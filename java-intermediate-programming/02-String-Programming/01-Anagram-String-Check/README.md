# Program 01 – Anagram String Check

## Description
This Java program checks whether two given strings are anagrams of each other. It removes whitespace, converts strings to lowercase, sorts their characters, and compares the resulting character arrays.

## Concepts Used
- Strings
- String Methods
- Character Arrays
- toCharArray()
- Arrays.sort()
- Arrays.equals()
- Conditional Statements
- Scanner Class

## Functionality
- Accepts two strings from the user.
- Ignores whitespace and letter case.
- Converts strings into character arrays.
- Sorts both character arrays.
- Compares the sorted arrays to determine whether the strings are anagrams.
