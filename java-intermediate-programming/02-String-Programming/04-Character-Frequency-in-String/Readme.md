# Program 04 – Character Frequency in a String
 
## Description
This Java program counts the frequency of each character in a given string using LinkedHashMap. It maintains the insertion order of characters and displays each character along with its occurrence count.

## Concepts Used
- Strings
- String Manipulation
- LinkedHashMap
- Map Interface
- Character Frequency
- getOrDefault()
- Entry Interface
- Enhanced for Loop

## Functionality
- Accepts a string from the user.
- Converts the string to lowercase.
- Ignores whitespace.
- Counts the occurrence of each character.
- Stores characters and their frequencies using LinkedHashMap.
- Displays each character with its frequency in insertion order.
