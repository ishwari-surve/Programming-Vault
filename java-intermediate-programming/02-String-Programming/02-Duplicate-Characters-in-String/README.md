# Program 02 – Find Duplicate Characters in a String

## Description
This Java program identifies duplicate characters in a given string and displays the frequency of each repeated character. It uses the HashMap collection to store characters and their occurrence counts.

## Concepts Used
- Strings
- String Manipulation
- HashMap
- Map Interface
- Character Frequency
- getOrDefault()
- Enhanced for Loop

## Functionality
- Accepts a string from the user.
- Converts the string to lowercase.
- Ignores whitespace.
- Counts the frequency of each character using HashMap.
- Identifies and displays duplicate characters with their frequencies.
- Displays a message if no duplicate characters are found.
