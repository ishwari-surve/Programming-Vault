# Program 015 – Reverse Each Word in a Sentence

## Description
This Java program reverses each individual word in a given sentence while maintaining the original order of the words. It uses the StringBuilder class and its reverse() method to perform word-wise reversal.

## Concepts Used
- Strings
- String Manipulation
- StringBuilder
- split() Method
- reverse() Method
- Loops
- Conditional Statements

## Functionality
- Accepts a sentence from the user.
- Splits the sentence into individual words.
- Reverses each word independently.
- Maintains the original order of words.
- Displays the original sentence and the modified sentence.
