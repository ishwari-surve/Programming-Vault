# Program 03 – First Non-Repeating Character in a String

## Description
This Java program finds the first non-repeating character in a given string. It uses LinkedHashMap to store characters and their frequencies while maintaining their original insertion order.

## Concepts Used
- Strings
- String Manipulation
- LinkedHashMap
- Map Interface
- Character Frequency
- getOrDefault()
- Enhanced for Loop
- Conditional Statements

## Functionality
- Accepts a string from the user.
- Converts the string to lowercase.
- Ignores whitespace.
- Counts the frequency of each character using LinkedHashMap.
- Identifies the first character that occurs only once.
- Displays a message if no non-repeating character exists.
