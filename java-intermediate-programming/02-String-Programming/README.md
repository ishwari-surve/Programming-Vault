# 02 – String Programming in Java

## Description
This section contains Java programs focused on string manipulation and problem-solving techniques. It covers intermediate-level string operations, character frequency analysis, searching, comparison, and transformation using Java's built-in String classes and collections.

Each program demonstrates practical string-handling techniques commonly used in Java development and technical interviews.

## Concepts Covered
- String Handling
- String Manipulation
- String Methods
- StringBuilder
- String Reversal
- Character Arrays
- Character Frequency Counting
- Anagram Checking
- HashMap
- LinkedHashMap
- Map Interface
- Duplicate Character Detection
- Non-Repeating Character Detection
- String Splitting
- Arrays.sort()
- Arrays.equals()
