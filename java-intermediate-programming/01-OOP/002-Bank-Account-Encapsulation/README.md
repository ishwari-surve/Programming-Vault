# Program 002 – Bank Account Management using Encapsulation

## Description
This Java program demonstrates the concept of **Encapsulation** by implementing a simple Bank Account Management System. It uses private data members and public methods to manage bank account information securely.

## Concepts Used
- Classes and Objects
- Encapsulation
- Private Data Members
- Public Methods
- Constructors
- Data Hiding

## Functionality
- Stores account number, account holder name, and balance.
- Deposits money into the bank account.
- Withdraws money with balance validation.
- Displays bank account details.
- Retrieves the current account balance.
