# Program 010 – Composition and Aggregation in Java

## Description
This Java program demonstrates two important Object-Oriented Programming relationships: Composition and Aggregation.

Composition represents a strong HAS-A relationship, where an object owns another object. Aggregation represents a weak HAS-A relationship, where an object references another independently existing object.

## Concepts Used
- Classes and Objects
- Composition
- Aggregation
- HAS-A Relationship
- Constructors
- Object References
- Encapsulation

## Functionality
- Creates an Engine object within the Car class to demonstrate Composition.
- Displays car details and engine information.
- Creates independent Teacher objects.
- Associates a Teacher object with a Department to demonstrate Aggregation.
- Displays department and teacher information.
