# Program 004 – Hierarchical Inheritance Demonstration

## Description
This Java program demonstrates hierarchical inheritance using an Employee parent class and two child classes: Developer and Manager.

Both child classes inherit common employee properties and methods from the parent class while maintaining their own specialized attributes.

## Concepts Used
- Classes and Objects
- Inheritance
- Hierarchical Inheritance
- Constructors
- super Keyword
- Code Reusability
- Method Implementation

## Functionality
- Defines a parent class named Employee.
- Creates Developer and Manager child classes.
- Inherits common employee details from the parent class.
- Uses the super keyword to initialize parent class variables.
- Displays role-specific employee information.
