# Program 003 – Multilevel Inheritance Demonstration

## Description
This Java program demonstrates multilevel inheritance using three classes: Vehicle, Car, and SportsCar. It shows how one class can inherit properties and methods from another derived class.

## Concepts Used
- Classes and Objects
- Inheritance
- Multilevel Inheritance
- extends Keyword
- Code Reusability

## Functionality
- Defines a base class named Vehicle.
- Derives the Car class from Vehicle.
- Derives the SportsCar class from Car.
- Accesses inherited variables and methods.
- Displays vehicle brand, model, and speed.
