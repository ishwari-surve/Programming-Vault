# Program 005 – Method Overloading and Method Overriding

## Description
This Java program demonstrates method overloading and method overriding, two important concepts of polymorphism.

Method overloading allows multiple methods with the same name but different parameter lists, while method overriding allows a child class to provide its own implementation of a parent class method.

## Concepts Used
- Classes and Objects
- Inheritance
- Polymorphism
- Method Overloading
- Method Overriding
- @Override Annotation

## Functionality
- Performs addition of two integers.
- Performs addition of three integers.
- Performs addition of two decimal numbers.
- Overrides the Add() method in the AdvancedCalculator class.
- Demonstrates compile-time and runtime polymorphism concepts.
