# Program 008 – Interface Implementation and Multiple Inheritance

## Description
This Java program demonstrates interface implementation and multiple inheritance using interfaces. The MultiFunctionPrinter class implements three interfaces: Printable, Scannable, and Faxable, providing implementations for all their methods.

## Concepts Used
- Interfaces
- Interface Implementation
- Multiple Inheritance using Interfaces
- implements Keyword
- Method Overriding
- @Override Annotation

## Functionality
- Defines three interfaces: Printable, Scannable, and Faxable.
- Implements all three interfaces in a single class.
- Provides implementations for printing, scanning, and faxing operations.
- Demonstrates how Java supports multiple inheritance through interfaces.
