# 01 – Object-Oriented Programming (OOP) in Java

## Description
This section contains Java programs based on Object-Oriented Programming (OOP) concepts. It covers the fundamental and intermediate principles of OOP, focusing on code reusability, modularity, abstraction, and polymorphism.

Each program demonstrates a specific OOP concept through practical Java implementations.

## Concepts Covered

- Classes and Objects
- Encapsulation
- Inheritance
- Single Inheritance
- Multilevel Inheritance
- Hierarchical Inheritance
- Method Overloading
- Method Overriding
- Compile-Time Polymorphism
- Runtime Polymorphism
- Dynamic Method Dispatch
- Abstraction
- Abstract Classes and Methods
- Interfaces
- Multiple Inheritance using Interfaces
- Constructor Chaining
- `this()` and `super()` Keywords
- Composition and Aggregation
