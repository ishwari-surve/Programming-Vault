# Program 001 – Employee Management System

## Description
A Java program that manages employee records using classes,
objects, constructors, and arrays of objects.

## Concepts Used
- Classes and Objects
- Constructors
- Instance Variables
- Methods
- Arrays of Objects
- Scanner Class

## Functionality
- Accepts multiple employee records.
- Stores employee ID, name, department, and salary.
- Displays all employee details.
